# EcoCampusGuide
EcoCampus Guide — веб-платформа для экологического мониторинга и управления устойчивым развитием в учебных заведениях. Проект создан в рамках индивидуального IT-проекта для автоматизации эко-инициатив, геймификации полезных привычек и повышения экологической грамотности старшеклассников (уровень B2–C1).
